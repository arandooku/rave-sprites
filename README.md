# Rave Master (Groove Adventure Rave) sprites

909 sprites split from 6 sheets archived by [Spriter Database](https://spritedatabase.net/game/1008) (GBA: Groove Adventure Rave — Hikari to Yami no Daikessen; Special Attack Force),
plus the whole sheets. One PNG per sprite, transparent background.

## Layout

```
sprites/<group>/<sheet>/<nnn>.png    one sprite, numbered in reading order
sheets/<sheet>.png                   the original sheet
thumbs/<sheet>.png                   small preview
index.json                           manifest
```

`index.json` → `entries: [[path, name, subcategory, category, file], ...]`, `cats: [[id, label], ...]`, `sheets`.

## URLs

```
https://raw.githubusercontent.com/arandooku/rave-sprites/v1/<file>
```

## Notes

- Sprites belong to Hiro Mashima / Kodansha / Konami; rips by the credited Spriter Database contributors. Unaffiliated fan archive for personal bead art.
- Split automatically (connected pixels, 2px merge gap, credit text removed); a few multi-part effects may split oddly — the whole sheet is always included.
- Generated by `beadwright/tools/export-sheet-repo.mjs rave`; do not edit by hand.
